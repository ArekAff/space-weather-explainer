# knowledge/sources/: articles and other sources to read and cite

PDF exports of papers, reports, standards and web pages worth keeping. The files are not in git (the GitHub repo is
public and most of them are under their publishers' copyright); they live here on the laptop and in OneDrive.
`sources_index.md` is in git and is the list of everything here.

## How to add a source

1. Save the file as `<year>_<first_author>_<short_title>.pdf`, lower case, underscores, no Polish letters.
   Example: `2019_camporeale_challenge_of_ml_in_space_weather.pdf`.
   A web page: print it to PDF and put the date you saved it in the index.
2. Add one row to `sources_index.md`.
3. When you have read it, set "Read" to yes and write one line on what it is useful for.

## Where else sources are listed

- Works used for the table of contents, with what was read in each: `thesis/spis_tresci_wzorce.md`.
- Papers proposed to the advisor: the current draft in `knowledge/advisor/emails_to_advisor/`.
- Data sources (not literature): `docs/zrodla_danych/`.
- The bibliography file for the thesis will be `thesis/latex/references.bib`; the citation key in the index is the
  key to use there.
